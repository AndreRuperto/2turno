# Design: logo e imagens do 2 Turno

Arquivos originais entregues pelo design. Esta pasta não é publicada no site; os arquivos
usados em produção são copiados depois para `frontend/public/`.

| Pasta | O que vai aqui |
|-------|----------------|
| `logo/` | Logo: horizontal (símbolo + nome), só o símbolo, versões monocromáticas clara e escura |
| `favicon/` | PNG 16×16, 32×32 e 180×180 (apple-touch-icon) |
| `hero/` | Imagem de abertura da página inicial: desktop (~1440×600) e celular (~390×500) |
| `social/` | Imagem de compartilhamento (og:image) 1200×630 |
